Reports variables declared in let-expressions and function parameters which are never used. Variables starting with an underscore (_) are ignored. Unused attributes of function arguments (e.g. { x }: ...) are only reported when enabled in the options, as they are often part of the interface of the function.

Example:

let unused = 1; in x: 42

This inspection requires the symbol support of NixIDEA, which is currently a preview feature. You can enable it in Settings | Languages & Frameworks | Nix | Symbols.
